Windows Support Reference

Common CMD Commands for Policy, Identity, and Network Diagnostics

A quick-reference guide for help desk, desktop support, and SOC-adjacent troubleshooting. Use these commands to identify the device, confirm user permissions, review Group Policy, and diagnose network or system issues.

Tip: Run Command Prompt or PowerShell as Administrator when checking system-level configuration, forcing policy updates, or repairing Windows system files.

The Group Policy Duo

Use these when a user says something like, “I can’t see the shared drive,” “My wallpaper hasn’t updated,” “My printer didn’t deploy,” or “I don’t have the right access.”

Force Policy Refresh

gpupdate /force
Purpose

Forces the computer and user account to pull the latest Group Policy settings from the domain controller.

Use When
  • Drive mappings, printers, or shortcuts are missing.
  • Security settings or desktop policies have not applied.
  • A user was recently added to a new security group.

Review Applied Policies

gpresult /r
Purpose

Shows which Group Policies are actually applying to the logged-in user and computer.

Use When
  • You need to confirm whether the user is receiving the correct policy.
  • You suspect the user is in the wrong Active Directory security group.
  • You need evidence before escalating to systems administration.
2

Network & Performance Diagnostics

DNS Lookup

nslookup hostname
Purpose

Checks whether a hostname resolves to the correct IP address.

Use When
  • A device or server cannot be reached by name.
  • You suspect DNS is pointing to the wrong IP.
  • You need to validate internal domain resolution.

IP Configuration

ipconfig /all
Purpose

Displays detailed network adapter information including IP address, DNS servers, DHCP status, MAC address, and gateway configuration.

Use When
  • You need to verify the device received a valid IP address.
  • You are checking DNS or DHCP configuration.
  • You need adapter information during ticket documentation.

Basic Connectivity Test

ping hostname-or-ip
Purpose

Tests connectivity between the local machine and another device or server.

Use When
  • You need to verify basic network communication.
  • A user cannot reach a server or website.
  • You need to identify packet loss or latency issues.

Trace Network Route

tracert hostname-or-ip
Purpose

Shows the path traffic takes across the network to reach a destination.

Use When
  • You suspect routing or ISP-related issues.
  • You need to identify where network traffic stops.
  • Users experience intermittent external connectivity.

Flush DNS Cache

ipconfig /flushdns
Purpose

Clears the locally cached DNS records stored on the computer.

Use When
  • DNS changes were recently made.
  • A hostname resolves incorrectly.
  • You suspect stale DNS cache entries.

Release and Renew DHCP Lease

ipconfig /release && ipconfig /renew
Purpose

Requests a new IP address from the DHCP server.

Use When
  • The device has an APIPA address (169.254.x.x).
  • The network adapter lost connectivity.
  • You need to refresh network configuration from DHCP.

Active Connections & Ports

netstat -ano
Purpose

Shows active network connections, listening ports, and the process ID using each connection.

Use When
  • You need to check whether a port is listening.
  • You suspect a background application is creating connections.
  • You want to match a connection to a running process.

Packet Loss by Hop

pathping hostname
Purpose

Combines ping and traceroute-style testing to identify where packet loss may be occurring.

Use When
  • Users report slow applications or intermittent connectivity.
  • You need to identify which network hop may be dropping packets.
  • Basic ping works but performance is still poor.

ARP Table

arp -a
Purpose

Displays IP-to-MAC address mappings learned by the local machine.

Use When
  • You suspect an IP address conflict.
  • You need to identify the MAC address associated with an IP.
  • You are troubleshooting local network communication.

System & User Identity

Logged-In User Groups

whoami /groups
Purpose

Shows the security groups and permission context for the currently logged-in user.

Use When
  • A user cannot access a shared drive, printer, or application.
  • You need to confirm group membership from the endpoint.
  • You want to compare local permissions against the ticket request.

System Inventory

systeminfo
Purpose

Generates a detailed system report, including OS version, memory, domain/workgroup status, hotfixes, and boot time.

Use When
  • You need to verify the computer’s last reboot time.
  • You need OS, patch, or system information for a ticket.
  • A user says they restarted, but you need to confirm.

Domain User Account Status

net user username /domain
Purpose

Checks domain account details such as password status, account lockout, group membership, last logon, and expiration information.

Use When
  • A user cannot log in.
  • You suspect the account is locked, disabled, or expired.
  • You need a fast check without opening Active Directory Users and Computers.
Common Parameters & Examples
net user username /domain

View domain account details, password status, group membership, and account expiration information.

net user username newpassword /domain

Reset a domain user's password. Use only when authorized and following company identity verification policy.

net user username /active:yes /domain

Enable a disabled domain user account.

net user username /active:no /domain

Disable a domain user account during offboarding, compromise response, or access removal workflows.

net user username /expires:never /domain

Set the account so it does not expire. Use carefully and only when policy allows.

net user username /passwordchg:yes /domain

Allow the user to change their password.

net user username /passwordchg:no /domain

Prevent the user from changing their password. This is usually reserved for special-purpose accounts and should follow policy.

Hardware & Cleanup

Network Adapter MAC Address

getmac
Purpose

Displays the physical MAC address of the network adapter.

Use When
  • You need the device MAC address for whitelisting.
  • You are documenting endpoint inventory.
  • You are verifying which adapter is active.

System File Checker

sfc /scannow
Purpose

Scans and repairs corrupted Windows system files.

Use When
  • Windows features are failing or behaving inconsistently.
  • Applications crash after updates or system changes.
  • You suspect system file corruption.

Suggested Troubleshooting Workflow

Use this flow when investigating access, policy, network, or endpoint issues:

  1. Identify the user and machine: Run whoami /groups and systeminfo.
  2. Confirm policy application: Run gpresult /r to see which policies are applied.
  3. Refresh policy if needed: Run gpupdate /force, then sign out or reboot if prompted.
  4. Validate DNS: Run nslookup hostname to confirm name resolution.
  5. Check connectivity and packet loss: Use pathping hostname when performance or packet loss is suspected.
  6. Review ports and processes: Use netstat -ano to identify active connections and listening ports.
  7. Check local network mapping: Use arp -a when investigating IP or MAC conflicts.
  8. Repair Windows system files: Use sfc /scannow when corruption or unstable Windows behavior is suspected.

Documentation Note: Capture relevant command output in the ticket, but sanitize usernames, domain names, IP addresses, MAC addresses, and internal server names before publishing screenshots or portfolio documentation.
